# Home Loan Tracker

แอปติดตามหนี้บ้านแบบ static PWA ใช้ Google Apps Script และ Google Sheets เป็นระบบกลาง

หน้าจอแบ่งเป็น 4 หมวด — ภาพรวม, แผนปลดหนี้, ประวัติและการชำระ, ตั้งค่า — และปรับขนาดตัวอักษรได้ 3 ระดับ โดยจดจำค่าที่เลือกไว้ในอุปกรณ์

## โครงสร้าง

- `loan_tracker.html` — โครงหน้าและหน้าต่างยืนยัน
- `styles.css` — รูปแบบทั้งหมดของแอป
- `js/app.js` — การแสดงผล การคำนวณ และการเชื่อมหน้าจอ
- `js/loan-analytics.js` — รวมลอจิกสรุปรายเดือน รายปี ลำดับประวัติ และการกรองข้อมูลที่ทดสอบแยกได้
- `js/receipt-parser.js` — แปลงข้อความจาก PDF/OCR เป็นข้อมูลใบเสร็จ
- `js/receipt-store.js` — คลังไฟล์ใบเสร็จใน IndexedDB ของอุปกรณ์
- `js/encrypted-backup.js` — สำรองใบเสร็จด้วย AES-256-GCM และรหัสที่ผู้ใช้กำหนด
- `js/sync-version.js` — จัดการเลขเวอร์ชันและตรวจข้อมูลชนกัน
- `apps-script/Code.gs` — backend ที่ใช้ ScriptLock และ optimistic concurrency
- `tests/` — ชุดทดสอบ parser, versioning และโครงสร้าง build

## ทดสอบ

```bash
npm install
npm run ci
```

GitHub Actions จะรันทั้ง unit tests และ Playwright บนมือถือ/เดสก์ท็อปทุกครั้งที่ push หรือเปิด pull request ครอบคลุมการสลับหน้า การกรองประวัติ หน้ากระทบยอด และการแนบรูปใบเสร็จ

## ใบเสร็จรูปภาพ

รูปถูกประมวลผลในเบราว์เซอร์ด้วย Tesseract.js ภาษาไทยและอังกฤษ ส่วน PDF ใช้ pdf.js ข้อมูลที่อ่านได้จะต้องผ่านหน้าตรวจสอบก่อนบันทึกเสมอ

ไฟล์ใบเสร็จไม่ถูกอัปโหลดไป Apps Script รูปจะถูกลดขนาดและเก็บใน IndexedDB เฉพาะอุปกรณ์ที่แนบไฟล์ สามารถส่งออกเป็นไฟล์ `.loanreceipts` ที่เข้ารหัสด้วย AES-256-GCM เพื่อย้ายหรือกู้คืนในอีกเครื่องได้

ตัวอ่าน PDF จะโหลดเมื่อผู้ใช้เลือกไฟล์ PDF เท่านั้น จึงไม่ถ่วงการเปิดหน้าแอปตามปกติ

## เปิดใช้การป้องกันข้อมูลพร้อมกัน

หน้าเว็บรองรับเลขเวอร์ชัน การตรวจสมการยอดชำระ ความต่อเนื่องของยอดคงเหลือ และ MRR กลางแล้ว แต่ต้อง deploy `apps-script/Code.gs` เป็นเวอร์ชันใหม่ด้วย ดูขั้นตอนที่ `apps-script/README.md`
