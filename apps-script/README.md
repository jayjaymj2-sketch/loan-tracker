# ตั้งค่า Apps Script สำหรับการป้องกันข้อมูลชนกัน

1. เปิด Apps Script ที่เชื่อมกับ Google Sheet ของแอป
2. แทนที่ `Code.gs` ด้วยไฟล์ `apps-script/Code.gs` ใน repository นี้
3. ที่ **Project Settings → Script properties** เพิ่มค่า:
   - `FAMILY_PASS_SHA256` — ค่า SHA-256 ของรหัสครอบครัว เป็นเลขฐาน 16 ตัวพิมพ์เล็ก 64 ตัว
   - `SPREADSHEET_ID` — ใส่เฉพาะเมื่อ Apps Script ไม่ได้ผูกอยู่กับ Google Sheet โดยตรง
   - หากอัปเกรดจากระบบเดิมที่มี `PASSPHRASE` อยู่แล้ว ไม่ต้องตั้งค่าใหม่ ระบบจะย้ายเป็น `FAMILY_PASS_SHA256` และลบข้อความเดิมให้อัตโนมัติเมื่อเข้าสู่ระบบครั้งแรก
4. Deploy เป็น Web app เวอร์ชันใหม่ โดยให้รันในชื่อเจ้าของ Sheet และอนุญาตผู้ใช้ที่มีลิงก์
5. คง URL `/exec` เดิมไว้ได้เมื่อแก้ deployment เดิม แอปหน้าเว็บจะเริ่มใช้เลขเวอร์ชันโดยอัตโนมัติ

ทุกคำสั่งเพิ่ม ลบ หรือนำเข้าจะทำงานภายใต้ `ScriptLock` และตรวจ `expectedVersion` ก่อนบันทึก หากอีกเครื่องแก้ข้อมูลก่อน คำสั่งจะถูกยกเลิกและหน้าเว็บจะโหลดข้อมูลล่าสุดมาให้ลองใหม่
